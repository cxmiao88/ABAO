# 二开工程说明

## 这是什么

这是 Coolify 的一个二次开发 fork，目标是把 Coolify 改造成一个**面向中文站长的服务器管理面板**——保留 Coolify 的部署自动化能力，补齐中文界面和宝塔式的服务器管理体验。

## 分支与标签

- `main`：当前开发分支（基于 Coolify v4.5.1，`93e7fa7`）
- `v4.5.1-base`：上游基线标签，锁定 fork 起点
- 将来合并上游时：新建 `upstream-sync` 分支，`git merge` 上游 tag，逐个解决冲突

## 快速开始（本机 WSL2）

```powershell
# 1. 启动 WSL（Coolify 数据在 WSL 内）
wsl -d Ubuntu

# 2. 同步代码到 WSL 并重启
wsl -d Ubuntu -- bash -c "rsync -av --delete /mnt/g/xianmu/juqing/baoUIIT/ /opt/coolify-src/ && cd /opt/coolify-src && docker compose up -d --build"

# 3. 访问
# http://localhost:8000
```

## 开发规范

1. 所有新功能优先**新增文件**，不改 Coolify 原有逻辑。
2. 每次提交前运行 `vendor/bin/pint --dirty --format agent`。
3. 翻译文件进版本库，禁止线上直接改。
4. 涉及多租户/权限的页面必须走 policy 鉴权。

## 关键目录速查
