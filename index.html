FAQ

常见问题

用「国内镜像」命令安装（页面顶部复制按钮，走 gh-proxy.com GitHub 加速通道；若不通可切换「国内备选」ghfast.top）。脚本内部也已针对国内网络优化：Docker 走腾讯云/阿里云源、源码与前端下载自动切换 ghproxy 加速通道、前端包支持源码目录直取/jsdelivr CDN/多源兜底。若某个环节仍超时，脚本会明确提示原因，并在 120 秒后自动重试。
ABao 是一个整合型面板：保留 Coolify（应用部署编排）与 mdserver-web（宝塔式主机管理）两个开源后端，用全新的 Vue 前端统一接管。安装后只需记住一个地址、一套账号。
为统一安全入口。Coolify 与 mdserver-web 的原登录页面已在安装时被面板接管，所有访问统一跳转到 ABao 登录页，避免多入口带来的管理混乱与安全面扩大。
没有。仓库内不含任何凭据，安装时由你交互设置管理员密码，数据库与 Redis 密钥随机生成，仅保存在服务器本地的 .env 文件中。
脚本支持 Ubuntu、Debian、CentOS、Rocky、AlmaLinux 等主流 Linux 发行版，x86_64 与 arm64 架构。建议 Ubuntu 22.04+ 或 Debian 12+。
完全开源（Apache-2.0），数据全部保存在你自己的服务器上，随时可以停止使用，正在运行的应用不受影响，不存在任何锁定。
拉取最新源码后重新执行安装脚本即可完成升级；前端面板随 GitHub Release 发布，脚本自动获取最新版本。
